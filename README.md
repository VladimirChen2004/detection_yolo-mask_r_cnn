# Детекция людей на видео: YOLOv11 и Mask R-CNN

## Описание проекта

Цель: написать программу на Python для автоматической детекции людей на видео с помощью двух современных моделей — YOLOv11 и Mask R-CNN (maskrcnn_resnet50_fpn).

В результате получается видео с визуально выделенными людьми, на каждом объекте отображаются имя класса и уверенность (score/confidence), при этом исходное содержимое кадра максимально сохранено, а боксы и подписи не перекрывают картину.

Результаты видео: https://drive.google.com/drive/folders/1SN4b4kWrK-xfDFjvty7fUDslEZ2sU5Re?usp=sharing

---

## Основные возможности

- **YOLOv11:**
  - Идеально распознает крупные и средние объекты.
  - Лучше работает для отслеживания проходящих людей, подсчета их количества, real-time мониторинга.
  - Настройки порогов позволяют адаптировать точность под задачу:
    - conf_threshold=0.3, iou_threshold=0.45 — детектирует большинство близлежащих людей, иногда ошибается (картину может принять за человека).
    - conf_threshold=0.55, iou_threshold=0.4 — детектирует только "передних" людей, отлично для контроля людей на проходе через турникеты (можно увеличить оба значения для более строгой фильтрации).
  - Недостатки: не видит мелких и дальних объектов (людей на мосту), иногда ошибается на фоновых объектах.

- **Mask R-CNN:**
  - Точнее, редко ошибается, видит дальних людей, нечувствителен к "похожим" на человека объектам (картины не выделяет).
  - score=0.3 — оптимально для толпы, площади, общего подсчёта количества.
  - score=0.5 — меньше боксов, лучше на среднем расстоянии; не всегда видит самых дальних.
  - Недостатки: работает медленно (меньше подходит для real-time).

## Примеры результатов

- YOLOv11, conf=0.3: хорошо выделяет ближних людей, иногда ошибается (см. фото 1, синие боксы).
- YOLOv11, conf=0.55: только "передние" (турникет/контроль прохода).
- Mask R-CNN, score=0.3: максимально полная детекция, в том числе дальние объекты (см. фото 2, зелёные боксы).
- Mask R-CNN, score=0.5: более строгая фильтрация, меньше ложных срабатываний (см. фото 3).

## Архитектура решений

1. **YOLOv11** — быстрый one-stage детектор, подходит для задач мониторинга и быстрой оценки.
2. **Mask R-CNN (ResNet-50-FPN)** — мощный two-stage детектор, отлично подходит для точных аналитических задач и сложных сцен.

## Запуск программы

1. **Укажите путь к своему видео** (например, crowd.mp4).
2. **Скрипт для YOLOv11**:

```python
from ultralytics import YOLO
import cv2
model = YOLO('yolo11m.pt')
conf_threshold = 0.3  # настройте по задаче
results = model('crowd.mp4', conf=conf_threshold, classes=[0], save=True, verbose=False)
```

3. **Скрипт для Mask R-CNN (PyTorch):**

```python
import cv2, torch
from torchvision.models.detection import maskrcnn_resnet50_fpn
model = maskrcnn_resnet50_fpn(pretrained=True).eval()
def detect(frame):
    img = torch.from_numpy(frame).permute(2,0,1).float()/255
    with torch.no_grad():
        pred = model([img])[0]
    return pred
# Обработка видео (см. файл process_video_maskrcnn.py)
```

4. В результате получится видео с подписанными людьми.
- Выделение объектов — аккуратные боксы с текстовой подписью "person" и уверенность (например, person 0.89).
- Детектируемые объекты не перекрывают исходное содержимое.

## Выводы

- **YOLOv11** — лучший выбор для быстрой и массовой детекции в реальном времени или на проходных точках.
- **Mask R-CNN** — если важна точность, аналитика, сложные сцены и детализация.
- Все видео выходят с минимальным перекрытием кадра и явными боксами/подписями классов.
- Эксперименты с порогами позволяют адаптировать систему под любые требования бизнеса: от мониторинга турникетов до аналитики толп.
